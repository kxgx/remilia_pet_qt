# 三项完善：动态资源增加 + 键盘键位显示 + 闹钟文字自适应

## 一、闹钟结束文字自适应（小改）
- `TimerWindow::updateScaleAndPosition` 补上 `m_statusLabel` 的样式刷新（按状态选字号：倒计时 22×scale、提醒文案 14×scale）——目前只有 tick 时才设字号，宠物缩放后文字不变

## 二、抽卡/画画资源动态增加
1. `DesktopPet` 新增公有 `numberedResourceCount(dir, base, ext)`：从 1 起逐个 `QFile::exists(resolveResourcePath(":/dir/baseN.ext"))` 直到缺失，返回数量（上限 999）
2. `DrawEffectWindow::revealCard` 的 `bounded(1, 56)` → 动态数量；`DrawingEffectWindow::startShow` 的 `bounded(1, 16)` → 动态数量——**放入 card_56.png / drawing_16.png 即可被抽到**（编号需连续）
3. `ResourceWindow::initUi`：55 张卡片后扫描覆盖目录中 card_56..（连续编号）追加行；15 张画作后同样追加 drawing_16..；行构建循环无需改动
4. 文档说明：新增资源放对应子目录、连续编号

## 三、键盘键位显示（新功能，单键 + 2 秒自动隐藏，右键+托盘双开关）
**新文件**：
- `src/keydisplaywindow.h/cpp`：粉框无边框置顶窗口（风格同其它侧窗），大字显示按键，2 秒无输入自动隐藏，随宠物缩放/贴靠（位置：宠物正上方）
- `src/keyhook.h`：统一接口 `startGlobalKeyListener / stopGlobalKeyListener / pollLinuxGlobalKey`
- `src/keyhook_win.cpp`：WH_KEYBOARD_LL 钩子（Qt 主线程消息泵），GetKeyboardState+ToUnicode 取字符（含 Shift/Caps），特殊键名映射（空格/回车/退格/方向键/Ctrl/Shift/Alt/Win/F1-F12）
- `src/keyhook_mac.mm`：CGEventTap（kCGEventKeyDown）+ CGEventKeyboardGetUnicodeString 取字符；**需 macOS 辅助功能/输入监控授权**（未授权则无显示，README 说明）
- `src/keyhook_linux.cpp`：XQueryKeymap 40ms 轮询 + XkbKeycodeToKeysym 取键名（Wayland 纯会话下无显示，XWayland 正常）

**集成**（petwindow.h/cpp）：
- `QPointer<KeyDisplayWindow> m_keyWindow`、`bool m_keyDisplayEnabled`（设置项 keyDisplay，saveSettings/loadSettings 往返）
- `toggleKeyDisplay()/applyKeyDisplay()`（沿用置顶/穿透模式）；右键菜单与托盘菜单各加勾选项「⌨ 键位显示」
- 键位回调 → 懒创建窗口 + `showKey(text)`；`updateSideWindowPositions`/`applyStayOnTop` 侧窗列表纳入 key 窗口；checkIdle 不将键位窗视为功能窗口

**构建**（CMakeLists.txt / build.yml）：
- keydisplaywindow 进公共 SOURCES；win/mac/linux 分别 APPEND 对应 hook 文件（.mm 自动按 ObjC++ 编译）
- Linux 加 `find_package(X11)` + 条件链接 X11::X11；build.yml 两个 Linux job 的 apt 列表加 `libx11-dev`

**Unicode 登记**（§1.15.1 / §1.15.5 / 新增 §1.15.9）：
- 菜单「`\u2328 \u952E\u4F4D\u663E\u793A` ⌨ 键位显示」
- 键名：空格 `\u7A7A\u683C`、回车 `\u56DE\u8F66`、退格 `\u9000\u683C`、方向键 `\u2191 \u2193 \u2190 \u2192`；其余键名用 ASCII（Shift/Ctrl/Alt/Win/F1-F12 等）
