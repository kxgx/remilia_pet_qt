==========================================
  绝区零蕾米埃尔桌宠 Qt6版 - 使用说明
==========================================

【运行环境】
- Windows 10 / 11 64位系统
- macOS 12+ (Apple Silicon / Intel)
- Linux x86_64 / ARM64

========================================
  Windows 使用方式
========================================
【便携版（zip压缩包）】
1. 下载后请【务必先解压压缩包】到任意文件夹。
2. 双击运行文件夹内的「蕾米埃尔桌宠_Qt6.exe」即可启动。

【安装版（Setup.exe）】
1. 双击运行安装程序，按提示完成安装。
2. 安装时可勾选「开机自动启动」，桌宠会在系统启动时自动运行。
3. 安装完成后可通过开始菜单或桌面快捷方式启动。

========================================
  macOS 使用方式
========================================
1. 下载 .dmg 文件后双击打开。
2. 将「蕾米埃尔桌宠_Qt6」拖入 Applications 文件夹。
3. 首次运行如提示「无法验证开发者」，请前往 系统设置 → 隐私与安全性 → 点击「仍要打开」。

========================================
  Linux 使用方式
========================================
1. 下载 .AppImage 文件。
2. 右键 → 属性 → 权限 → 勾选「允许作为程序执行」（或运行 chmod +x *.AppImage）。
3. 双击运行即可，无需安装。

==========================================
  操作指南与功能介绍
==========================================
【左键拖拽】
- 按住桌宠左键可自由拖动至桌面任意位置。
- 所有侧边功能弹窗与右键菜单均会平滑跟随桌宠移动。

【左键点击】
- 左键点击桌宠可触发互动表情反馈与音效。
- 倒计时进行或提醒锁定期间，点击互动将自动屏蔽，避免打断功能。

【鼠标滚轮】
- 在桌宠上方滚动鼠标滚轮，可实现【自由无极缩放】桌宠大小（30% ~ 300%）。
- 音量条、画画展框、倒计时及制作声明等侧边弹窗会平滑无缝同步缩放。

【右键互动菜单】
右键点击桌宠即可调出粉色互动菜单（固定显示于桌宠右侧标准位置）：
  - ✨ 幸运抽卡：播放抽卡动画与音效，动画结束后随机掉落调频卡牌结果。
  - ⏰ 闹钟计时：自定义设定分/秒倒计时，计时结束触发动画提醒与警报音效。
  - 🎨 随机画画：桌宠进入画画状态，结束后在右侧展示随机画作。
  - 🔊 音量调节：弹出竖向粉色滑动条，实时平滑调节桌宠所有音频与混音音量。
  - ℹ️ 制作声明：查看桌宠设计作者信息与免费声明。
  - ↺ 重置大小：一键将桌宠缩放比例恢复至 100% 标准大小并播放提示音。
  - ✕ 退出桌宠：安全关闭桌宠程序。
